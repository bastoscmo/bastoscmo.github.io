Here are the development projects focused on tools, scripts, and interfaces for computational physics and materials science:

## 1. [Siesta Toolbox (STB)](/development/siesta-toolbox/)
A comprehensive Python-based suite developed to streamline the workflow with the **SIESTA** code. It offers robust tools for automation and post-processing, including:
* **Automation:** Scripts to manage and execute multiple simulation steps.
* **Analysis:** Extraction and visualization of Electronic Band Structures, Projected Density of States (PDOS), Elastic Constants, Stress-Strain curves, among others.
* **Status:** Active
* [View Project Page](/development/siesta-toolbox/)

## 2. [Wantibexos Interfaces](/development/wantibexos/)
Interface tools designed to bridge Density Functional Theory (DFT) calculations with the **Wantibexos** code.
* **Functionality:** These interfaces convert DFT-derived Hamiltonians into formats compatible with Wantibexos.
* **Applications:** Enables the calculation of excitons (Bethe-Salpeter Equation), electronic band structures, and optical properties using the converted Hamiltonians.
* **Status:** Under Development
* [View Project Page](/development/wantibexos/)

## 3. [Aims Toolbox](/development/aims-toolbox/)
A collection of utility scripts and tools analogous to the STB, but tailored specifically for the **FHI-aims** software package.
* **Functionality:** Facilitates the pre-processing of inputs and the post-processing of data from all-electron simulations.
* **Status:** Under Development
* [View Project Page](/development/aims-toolbox/)
