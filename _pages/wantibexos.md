## Introduction

Interface tools designed to bridge Density Functional Theory (DFT) calculations with the **Wantibexos** code.

* **Functionality:** These interfaces convert DFT-derived Hamiltonians into formats compatible with Wantibexos.
* **Applications:** Enables the calculation of excitons (Bethe-Salpeter Equation), electronic band structures, and optical properties using the converted Hamiltonians.
